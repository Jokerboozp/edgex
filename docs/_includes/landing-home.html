Why edgeCore

为严苛工业现场打造

从调度内核到状态模型，每一层都围绕长期稳定运行设计。

01 AI Native

MCP 协议对接 LLM

支持 Model Context Protocol，让大语言模型能够安全、实时地读取设备状态、查询点位与诊断故障， 开启 AI 工业运维新体验——无需把现场数据搬到云端。

AI-Native Industrial Gateway
02 Reliability

工业级 SLA 保障

内置指标门控、Soak 长稳回归与 CI 五道 gate；1 万点位压测稳定无内存泄漏。 ConnectionManager 提供统一连接状态机、指数退避重连与冷却期策略。

10k点位压测规模
5CI 质量 gate

03 Scheduler

ScanEngine 调度内核

10ms Tick 驱动优先级队列，EDF 最早截止优先与 hard jitter clamp，自适应节流与设备级熔断隔离。

P99 <150ms · ≤10k tag
04 State

ShadowCore 影子真源

点位值的内存事实来源：写时复制快照、环形缓冲写入、分钟级持久化。UI、边缘计算与北向接口统一从影子读取。

Single Source of Truth
05 Edge Compute

虚拟影子与规则引擎

跨通道引用计算点与聚合点，公式依赖图 + 表达式求值 + 批量动作，本地执行联动控制，无需云端往返。

Virtualization & Rule Engine
06 Deployment

轻量部署，单二进制交付
